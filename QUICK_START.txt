🚀 GET STARTED IN 3 STEPS:

1. Navigate to project:
   cd manufacturing-website

2. Run development server:
   npm run dev

3. Open in browser:
   http://localhost:3000

🎯 FIRST CUSTOMIZATION STEPS:

1. Update company info in: lib/data.ts
2. Replace contact details throughout
3. Add your images to: public/hero/, public/portfolio/, public/logos/
4. Customize services in: lib/data.ts
5. Update process steps in: lib/data.ts
